# Security policy

Graph-AI is local-first and does not send repository contents to any service.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to the maintainers through the GitHub organization contact path, including affected version, reproduction steps, and impact.

## Sensitive data

Graph-AI skips common secret filenames and respects Git ignore rules, but it is not a secret scanner. Do not rely on it as the sole control preventing credentials from being committed.
